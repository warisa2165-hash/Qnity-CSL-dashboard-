# เริ่มต้นใช้งาน (ทุกคนอ่าน)

## 1. เข้าสู่ระบบ

1. เปิดเบราว์เซอร์ (Chrome, Edge, Safari หรือ Firefox)
2. ไปที่ https://qnity-csl-dashboard.vercel.app
3. ระบบจะพาไปหน้า **Sign in** โดยอัตโนมัติ

ในหน้า Sign in จะเห็น:

- กล่องสีเหลือง **"Microsoft Entra ID is not configured"** — ถูกต้องแล้ว
  ระบบยังไม่ได้เชื่อมต่อ Single Sign-On ของ QNITY จึงใช้บัญชีทดสอบไปก่อน
- **Demo account** — เลือกบัญชีที่ตรงกับบทบาทของคุณ
- **Demo password** — ใส่รหัสผ่านที่ผู้ดูแลระบบแจ้ง
- กด **Continue with demo account**

> รหัสผ่านเป็นรหัสเดียวกันสำหรับทุกบัญชี ขอจาก Warisa Kantifong

**ระยะเวลาเข้าใช้งาน** — ระบบจะจำการเข้าสู่ระบบไว้ 8 ชั่วโมง หลังจากนั้น
ต้องเข้าสู่ระบบใหม่

## 2. ส่วนประกอบของหน้าจอ

| ตำแหน่ง | ส่วนประกอบ | ใช้ทำอะไร |
|---|---|---|
| บนซ้าย | โลโก้ **Q** + ชื่อโครงการ | กดเพื่อกลับหน้าแรก |

| บนขวา | ไอคอนดวงอาทิตย์/ดวงจันทร์ | สลับธีมสว่าง–มืด (Light / Dark / System) |
| บนขวา | วงกลมย่อชื่อ | เมนูผู้ใช้ · ดูบทบาทของตน · ออกจากระบบ (Sign out) |

## 3. อ่านสถานะสัญญาณไฟจราจร

ทั้งระบบใช้สีเดียวกันตลอด:

| สี | ความหมาย | ต้องทำอะไร |
|---|---|---|
| 🟢 **เขียว** | On Track — เป็นไปตามแผน | ติดตามตามปกติ |
| 🟡 **เหลือง** | On Track with Watch Items — ตามแผนแต่มีจุดต้องเฝ้าระวัง | เฝ้าดูใกล้ชิด |
| 🔴 **แดง** | Critical / Management Attention Required — วิกฤต ต้องการการตัดสินใจจากผู้บริหาร | เร่งดำเนินการ |

## 4. ค้นหาข้อมูล

กด **`Ctrl+K`** (Windows) หรือ **`⌘K`** (Mac) แล้วพิมพ์อย่างน้อย 2 ตัวอักษร
ค้นได้ทั้ง Milestone, Risk, Action, เอกสาร, อุปกรณ์ CAPEX และรายการจัดซื้อ

ใช้ปุ่มลูกศร ↑ ↓ เลือก แล้วกด `Enter`

> ผลการค้นหาจะแสดงเฉพาะข้อมูลในหน้าที่คุณมีสิทธิ์เข้าถึงเท่านั้น

## 5. ใช้ตารางข้อมูล

ทุกหน้าที่มีตารางจะมีเครื่องมือชุดเดียวกัน:

- **ช่องค้นหา** — พิมพ์คำที่ต้องการกรอง
- **ตัวกรอง (Filter)** — เลือกจากรายการ เช่น สถานะ ผู้รับผิดชอบ
- **เรียงลำดับ** — คลิกที่หัวคอลัมน์
- **Export CSV** — ดาวน์โหลดไปเปิดใน Excel (ได้เฉพาะข้อมูลที่กรองไว้)
- **Clear** — ล้างตัวกรองทั้งหมด

ผู้ดูแลระบบมีสิทธิ์เข้าถึงทุกหน้าและทุกข้อมูล รวมถึง **Admin Panel**
ซึ่งผู้ใช้บทบาทอื่นมองไม่เห็น

## 1.1 งานประจำวัน

### ตรวจสอบสถานะโครงการ

เข้า **Executive Dashboard** เป็นหน้าแรกทุกครั้ง ดูตามลำดับนี้:

1. **แถบสถานะโครงการด้านบน** — สีบอกสุขภาพโครงการโดยรวม
2. **KPI 10 ช่อง** — ความคืบหน้า, คะแนนความปลอดภัย, ความเสี่ยงเปิดค้าง,
   งานเกินกำหนด, รายการรออนุมัติ
3. **Owner attention required** — เรื่องที่ต้องให้ผู้บริหารตัดสินใจ
4. **Top 5 risks** และ **Top overdue actions** — สามอันดับแรกที่ควรจัดการ

ตัวเลข KPI ทั้งหมดคำนวณสดจากข้อมูลจริงในระบบ ไม่ได้พิมพ์ค้างไว้
จึงไม่มีทางขัดแย้งกับหน้ารายละเอียด

### ติดตามตารางงานและความล่าช้า

เข้า **Project Phases** เพื่อดู:

- **แถบสรุปด้านบน** — พยากรณ์วันส่งมอบเทียบกับวันที่รับปากไว้
- **SPI (Schedule Performance Index)** — ต่ำกว่า 1.00 = ช้ากว่าแผน
- **Recovery required** — ต้องเร่งกี่วันจึงจะทันกำหนด
- **แผนภูมิ Gantt** — แถบประ = แผนเดิม, แถบทึบ = ผลงานจริง,
  **แถบลายทแยงสีแดง = ความล่าช้า**
- **CP** = อยู่บนเส้นทางวิกฤต (Critical Path) คือกิจกรรมที่กำหนดวันส่งมอบ
- **Delay analysis and recovery** — สาเหตุความล่าช้าและแผนเร่งรัด

### จัดการงานค้าง

เข้า **Action Tracker** กรองด้วย Status = `OVERDUE` เพื่อดูงานเกินกำหนด
พร้อมผู้รับผิดชอบและบริษัท

## 1.2 Admin Panel — จัดการผู้ใช้และสิทธิ์

เข้าเมนู **Admin Panel** (อยู่กลุ่ม ADMINISTRATION ล่างสุด)
มี 5 แท็บ

### แท็บ User management — จัดการผู้ใช้

**เพิ่มผู้ใช้ใหม่**
1. กด **Invite user**
2. กรอกชื่อ, อีเมล, องค์กร, ตำแหน่ง
3. เลือกบทบาท (Role)
4. กด **Send invitation**

**แก้ไขสิทธิ์รายบุคคล**
1. กด **Manage** ที่แถวของผู้ใช้
2. เปลี่ยน **Role** หรือ **Account status** ได้
3. ตารางด้านล่างกำหนดสิทธิ์ราย**หน้า**ได้:
   - **Grant edit** — ให้สิทธิ์แก้ไขหน้านั้นเป็นพิเศษ
   - **Deny access** — ห้ามเข้าหน้านั้น แม้บทบาทจะอนุญาตก็ตาม
4. กด **Save changes**

> **กฎสำคัญ:** การห้าม (Deny) มีผลเหนือทุกอย่างเสมอ แม้แต่สิทธิ์ผู้ดูแลระบบ
> ทำให้คุณกำหนดนโยบายได้ทุกรูปแบบโดยไม่ต้องสร้างบทบาทใหม่

**ระงับ / ลบผู้ใช้**
- **Disable** — ระงับชั่วคราว เข้าระบบไม่ได้แต่ประวัติยังอยู่
- **ไอคอนถังขยะ** — ลบถาวร

> ระบบป้องกันไม่ให้คุณระงับ ลดสิทธิ์ หรือลบบัญชีผู้ดูแลระบบของตัวเอง
> เพื่อไม่ให้ล็อกตัวเองออกจากระบบ

### แท็บ Access requests — อนุมัติคำขอเข้าใช้งาน

คนภายนอกที่ยังไม่มีบัญชีจะยื่นคำขอผ่านหน้า `/request-access`
คำขอจะมารออยู่ที่นี่

1. อ่านเหตุผลที่ผู้ขอระบุ (justification)
2. เลือกบทบาทที่จะให้ในช่อง **Assign role**
3. กด **Approve** หรือ **Reject**

> คำขอไม่สามารถขอสิทธิ์ Admin ได้ ระบบจะลดเป็น Leadership อัตโนมัติ

### แท็บ Permissions — ดูสิทธิ์พื้นฐานของแต่ละบทบาท

ตารางแสดงว่าบทบาทใดเข้าหน้าใดได้บ้าง (View / Edit / —)
เป็นข้อมูลอ้างอิงอย่างเดียว แก้ไขรายบุคคลได้ที่แท็บ User management

### แท็บ Data management — นำเข้า/ส่งออกข้อมูล

- **Export** — ดาวน์โหลดทะเบียนต่าง ๆ เป็น CSV เปิดใน Excel ได้ทันที
- **Import** — นำเข้าจาก CSV (ต้องเชื่อมฐานข้อมูลก่อนจึงใช้ได้)

### แท็บ Audit trail — ประวัติการใช้งาน

บันทึกทุกการกระทำ: เข้าสู่ระบบ, สร้าง, แก้ไข, ลบ, อนุมัติ, ปฏิเสธ,
อัปโหลด, ดาวน์โหลด, เปลี่ยนสิทธิ์ และ**ความพยายามเข้าถึงที่ถูกปฏิเสธ**

กรองได้ตามการกระทำ, ประเภทข้อมูล, ผู้ใช้ และส่งออกเป็น CSV
เพื่อแนบในเอกสารส่งมอบโครงการ

# ส่วนที่ 3 — สำหรับผู้เยี่ยมชม (Visitor)

> **ผู้เยี่ยมชม** หมายถึงผู้ที่มีลิงก์เว็บไซต์ แต่**ยังไม่มีบัญชี**
> หรือยังไม่ได้รับรหัสผ่าน

## 3.1 สิ่งที่ผู้เยี่ยมชมเห็น

เมื่อเปิดลิงก์ จะเห็นได้เพียง **หน้า Sign in** เท่านั้น

หากพยายามเข้าหน้าอื่นโดยตรง เช่น `/dashboard` ระบบจะพากลับมาหน้า Sign in
ทันที **ไม่มีข้อมูลโครงการใด ๆ รั่วไหล**

หน้าที่เปิดสาธารณะมีเพียง 3 หน้า:

| หน้า | ใช้ทำอะไร |
|---|---|
| `/login` | เข้าสู่ระบบ |
| `/request-access` | ยื่นคำขอเข้าใช้งาน |
| `/no-access` | แจ้งว่าไม่มีสิทธิ์เข้าหน้าที่ขอ |

## 3.2 วิธีขอสิทธิ์เข้าใช้งาน

1. ที่หน้า Sign in กดลิงก์ **"Request portal access"** ด้านล่างสุด
   (หรือเข้า https://qnity-csl-dashboard.vercel.app/request-access)
2. กรอกข้อมูล:
   - **Full name** — ชื่อ-นามสกุล
   - **Work e-mail** — อีเมลบริษัท
   - **Organisation** — องค์กร (QNITY / SYME072 / Design Alternative / Vendor)
   - **Requested role** — บทบาทที่ขอ (ระบบอธิบายแต่ละบทบาทให้ใต้ช่อง)
   - **Business justification** — เหตุผล **อย่างน้อย 20 ตัวอักษร**
3. กด **Submit access request**

> **เคล็ดลับ** — ในช่องเหตุผล ให้ระบุชัดว่าต้องการเข้าถึง**ส่วนไหน**
> ของระบบ เพราะผู้ดูแลกำหนดสิทธิ์ได้ละเอียดถึงระดับรายหน้า

4. รอผู้ดูแลระบบ (Warisa Kantifong) พิจารณา
   จะได้รับแจ้งผลทางอีเมลที่กรอกไว้

## 3.3 ข้อควรทราบ

- คำขอ**ไม่สามารถ**ขอสิทธิ์ผู้ดูแลระบบได้
- ผู้ที่ไม่ได้อยู่ในโดเมน `qnity.com` จะถูกทำเครื่องหมายเป็น
  **ผู้ใช้ภายนอก (External)** และอาจถูกจำกัดสิทธิ์เพิ่มเติม
- เว็บไซต์นี้ตั้งค่า `noindex` — Google และ Search Engine อื่นจะไม่แสดงผล
  แต่**ไม่ใช่**การควบคุมการเข้าถึง ผู้ที่ได้รับลิงก์ต่อยังเปิดได้

# ภาคผนวก — ข้อจำกัดของรุ่น UAT

รุ่นที่ใช้งานอยู่ขณะนี้เป็นรุ่นทดสอบด้วยข้อมูลสมมติ
สิ่งต่อไปนี้**ไม่ใช่ข้อผิดพลาด** แต่เป็นข้อจำกัดที่ตั้งใจไว้

| หัวข้อ | สถานะปัจจุบัน |
|---|---|
| **ข้อมูลทั้งหมด** | เป็นข้อมูลตัวอย่างสมมติ ไม่ใช่ข้อมูลโครงการจริง |
| **การบันทึกข้อมูล** | การแก้ไขจะถูกตรวจสอบสิทธิ์และบันทึกลง Audit trail แต่**ไม่ถูกเก็บถาวร** เมื่อรีเฟรชจะกลับเป็นค่าเดิม |
| **อัปโหลด/ดาวน์โหลดไฟล์** | ปิดใช้งาน (ปุ่มเป็นสีเทา) เพราะระบบยังไม่มีที่เก็บไฟล์ |
| **Audit trail** | แสดงประวัติตัวอย่าง รายการใหม่จะไม่ปรากฏในตาราง |
| **Microsoft Entra ID** | ยังไม่ได้เชื่อมต่อ ใช้บัญชีทดสอบไปก่อน |
| **วันที่อ้างอิงข้อมูล** | ข้อมูลตรึงไว้ที่ 01 สิงหาคม 2026 ยิ่งเวลาผ่านไป จำนวน "เกินกำหนด" จะยิ่งเพิ่มขึ้น เป็นเรื่องปกติของข้อมูลตัวอย่าง |
